Fast Track Ultra Driver

Use your M-Audio Fast Track Ultra with audio applications on an Apple Silicon Mac.

This is an experimental development build. Playback has been tested on the desktop Fast Track Ultra at 48 kHz. Fast Track Ultra 8R is included in the same driver but has not been tested on hardware. DAW, recording and sleep/wake qualification are still in progress.

Requires an Apple Silicon Mac and macOS 14 or later. This minimum version does not mean every macOS release has been tested.

Quit audio applications before continuing. Installation asks for an administrator password and briefly interrupts all audio. An existing Fast Track Ultra driver is backed up. Other audio drivers and your selected output device are left alone.

No Rust, Python, Xcode or Terminal commands are required to use this package.
